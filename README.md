# 🚀 100 Days, 100 Projects  

### 💡 One project a day. No excuses. Just code.  

Welcome to my **100 Days, 100 Projects** challenge! 🎯 Every day for 100 days, I built a **mini project** using **HTML, CSS, and JavaScript.** Some are fun games, some are useful tools, and some... well, let's just say they were experiments. 😆  

---

## **🛠 Tech Stack**
- **Frontend:** HTML, CSS, JavaScript  
- **No fancy libraries**—just raw JS magic ✨  

---

## **📂 What's Inside?**  
🔹 **Mini Games** (Snake, Tic-Tac-Toe, Memory Game & more)  
🔹 **Tools & Utilities** (To-Do List, Countdown Timer, Weather App)  
🔹 **Cool Animations** (Hover effects, loaders, buttons)  
🔹 **Random Fun Stuff** (Guess the Number, Trivia Quiz)  

Each project is **small, beginner-friendly, and focused on one key concept**.  

---

## **🚀 Why I Did This?**
- To stay consistent & improve my JS skills  
- To push myself beyond tutorials  
- To just have fun building cool stuff!  

---

## **📜 How to Use?**
1️⃣ Clone the repo  
2️⃣ Open any project folder  
3️⃣ Run the `index.html` file in your browser  
4️⃣ Enjoy the magic! ✨
